# 🧠 Mental Health Tracker
A console-based Mental Health Tracker designed to help users monitor their mood, habits, and overall well-being.

This project is developed as part of the SDG 3: Good Health and Well-being initiative, aiming to promote mental awareness through simple daily tracking.
- 📅 Daily mood tracking
- 📝 Notes/journal entries
- 📊 Simple progress overview
- 🔐 User-friendly console interface
- 💾 Data storage (file or database)
- - Language: [Java]
- Concepts: Object-Oriented Programming (OOP)

- 1. Clone the repository:
   git clone https://github.com/Youssef-006/mental-health-tracker.git

2. Open the project in your IDE

3. Compile and run the main file
4. - main.cpp / Main.java → Entry point
- User class → Handles user data
- Tracker class → Handles mood tracking
- FileHandler → Manages saving/loading data
- This project supports the United Nations Sustainable Development Goal 3:
Good Health and Well-being, by encouraging users to track and reflect on their mental health.
